## 0. 왜 개편하나

현재 빌드가 단편적으로 느껴지는 원인:

1. **카드가 전부 "숫자 +n"이다.** 패시브 12종과 총기 개조 4종이 서로 관계가 없어서, A를 고르면 B의 가치가 오르는 구조가 없다.
2. **진짜 선택은 스킬 Lv3 분기 A/B 한 번뿐**이고, 그마저 대부분 수치 차이다.
3. **진화가 1:1 고정**(클래식↔C, 셰리프↔Q)이라 총을 사는 순간 정답 경로가 정해진다.
4. 결과적으로 판마다 "같은 스킬을 다른 순서로 올리는" 경험이 된다.

**목표 한 줄**: 요원의 킷(C/Q/E/X)과 고유 패시브는 고정하되, 그 스킬이 **어떤 모양으로 변하고 무엇과 맞물리는지**는 판마다 달라지게 한다. 판이 끝났을 때 "이번 판 체임버는 지뢰밭 체임버였다"라고 말할 수 있어야 한다.

## 1. 설계 원칙

1. **정체성 고정점은 건드리지 않는다.** 요원 고유 패시브가 먹는 연결고리(체임버 = 감속 필드, 킬조이 = 설치물·취약)는 어떤 증강도 끊을 수 없다. 트레이드마크의 모든 형태는 반드시 감속 필드를 만들고, 킬조이 설치물의 모든 형태는 `설치물` 태그를 유지한다.
2. **스킬은 형태가 바뀌어도 동사는 남는다.** 덫은 덫, 귀환은 귀환이다. 다만 "덫 5개 지뢰밭"과 "거대 덫 1개"는 완전히 다른 플레이가 된다.
3. **모든 것은 태그로 엮인다.** 스킬·총·카드·유틸·유물이 같은 태그 언어를 쓴다. 새 요원을 추가해도 기존 카드가 자동으로 맞물린다.
4. **조건부 효과가 수치보다 우선이다.** "~할 때 ~한다"가 연쇄되면서 플레이어가 스스로 엔진을 발견하는 것이 빌드의 재미다.
5. **트레이드오프가 방향을 만든다.** 장점만 있는 선택은 방향을 만들지 못한다. 유물과 일부 카드는 의도적으로 단점을 가진다.
6. **자동화는 성장의 보상이다.** 기본은 수동 시전. 숙련 증강에서 "반자동화"를 고를 수 있어서, 초반엔 손이 바쁘고 후반엔 빌드가 손을 대신한다.

## 2. 빌드 구성 요소 한눈에

| 요소 | 얻는 곳 | 재화 | 무엇을 바꾸나 | 장 |
|---|---|---|---|---|
| 스킬 레벨 | 레벨업 카드 | XP | 수치 | 4 |
| **형태 증강** | 스킬 Lv2 도달 시 3지선다 | XP | 스킬의 동작 방식 | 4~6 |
| **숙련 증강** | 스킬 Lv5 도달 시 3지선다 | XP | 트리거·자동화 | 4~6 |
| **전술 카드** | 레벨업 카드 | XP | 태그 간 조건부 효과 | 7 |
| 생존 패시브 | 레벨업 카드 | XP | 기본 체급 | 7.3 |
| 총기 / 티어 / 개조 | 상점 / 레벨업 | 크레딧 / XP | 화력의 뼈대 | 8 |
| **태그 공명 진화** | 총 티어 3 + 태그 4개 | - | 총의 성격 | 8.5 |
| **유틸 슬롯 (용병 계약)** | 상점 | 크레딧 | 다른 요원의 경량 스킬 1개 | 9 |

## 3. 태그와 상태이상

### 3.1 태그

모든 피해원(투사체, 장판 틱, 폭발, 빔)과 모든 빌드 요소에 태그를 단다. `src/data/tags.js`에 둔다.

| 태그 | 의미 | 대표 출처 |
|---|---|---|
| `총기` | 플레이어 총 피해 | 모든 총 |
| `보조` | 보조무기 피해 | 클래식, 셰리프 |
| `저격` | 고위력 단발·관통 | 오퍼레이터, 헤드헌터, 투르 드 포스 |
| `산탄` | 펠릿 | 저지 |
| `설치물` | 설치형 장치의 피해·효과 | 덫, 알람봇, 포탑, 나노스웜 |
| `장판` | 지속 영역 | 감속 필드, 나노스웜 장판 |
| `폭발` | 순간 광역 피해 | 덫 폭발형, 알람봇, 대폭발 |
| `이동기` | 위치 이동 | 랑데뷰, 순풍 |
| `재장전` | 탄창 순환 | 8.1의 탄창 시스템 |
| `크리` | 크리티컬 | 집중포화, 헤드샷 |
| `감속` | 냉각 상태이상 | 감속 필드, 냉각탄 |
| `취약` | 취약 상태이상 | 알람봇, 부식 |
| `구금` | 구금 상태이상 | 락다운, 과충전 덫 |
| `표식` | 표식 상태이상 (신규) | 표식 사격, 정찰 화살 |
| `제압` | 제압 상태이상 (신규) | 제로/포인트, 제압 프로토콜 |
| `경제` | 크레딧·XP 획득 | 금괴 탄, 도박꾼 |

투사체와 피해 이벤트는 `tags: [...]` 배열을 가진다. 명중 파이프라인은 태그를 보고 배율을 합산한다(예: "폭발 피해 +20%"). 지금의 `GADGET_SOURCES`(천재성 판정)는 `설치물` 태그 검사로 대체한다.

### 3.2 상태이상

| 상태 | 효과 | 비고 |
|---|---|---|
| 냉각(감속) | 이동 감속 | 기존 |
| 취약 | 받는 피해 ×1.1 | 기존 |
| 구금 | 이동·사격 정지 | 기존, 엘리트·보스 저항 |

| **실명** (신규) | 사격 정지, 이동 방향 무작위 | 섬광 유틸 |

## 4. 스킬 성장 구조

### 4.1 레벨과 증강

| 레벨 | 내용 |
|---|---|
| Lv1 | 해금 (C는 시작 시 보유) |
| **Lv2** | **형태 증강** 선택: 그 스킬의 형태 풀에서 3개 제시, 1개 선택 |
| Lv3, Lv4 | 수치 강화 |
| **Lv5** | **숙련 증강** 선택: 그 스킬의 숙련 풀에서 3개 제시, 1개 선택 |

- 기존 Lv3 분기 A/B는 **형태 풀로 흡수**한다(기존 A/B가 형태 후보 중 두 개가 된다). 선택 흐름은 지금의 분기 `pending`을 그대로 재사용한다.
- **형태 증강은 Lv2로 확정** (v0.2.1). 해금 직후 한 번만 더 올리면 형태가 바뀌어 빌드 체감이 빠르다.
- 형태는 스킬당 4~5개, 숙련은 스킬당 4개. 숙련 풀에는 항상 **자동화 증강 1개**가 있다. 스킬 자동 사용 중에는 자동화 증강이 다른 효과로 바뀐다 (21.4).
- **모든 형태·숙련 증강은 자동 전투 규칙(`auto`)을 함께 가진다** (21장). 규칙이 없는 증강은 추가하지 않는다.
- 12라운드 목표 레벨 18~22, 스킬 4개 × 5레벨 = 20업이고 전술 카드와도 경쟁하므로, 한 판에 숙련 증강은 보통 1~2개만 찍힌다. 즉 **무엇을 Lv5까지 밀지가 빌드 방향**이 된다.

## 5. 체임버

### 5.1 정체성 고정점

- **집중포화**: 감속 필드 안의 적은 모든 피해가 크리. 변경 없음.
- 동사: **덫을 깐다 / 정밀하게 쏜다 / 귀환한다.**
- 모든 트레이드마크 형태는 감속 필드를 만든다.

### 5.2 목표 아키타입

| 아키타입 | 핵심 태그 | 한 줄 |
|---|---|---|
| 덫 사냥꾼 | 설치물·장판·감속 | 맵을 덫으로 뒤덮고 필드 안에서 크리 폭격 |
| 원샷 저격수 | 저격·크리·관통 | 적게 쏘고 크게 지운다 |
| 귀환 교란자 | 이동기·재장전 | 덫과 덫 사이를 순간이동하며 싸운다 |
| 무기상 | 경제·총기 | 체임버는 무기 디자이너다. 돈이 곧 화력 |

### 5.3 트레이드마크 (C)

**형태**

| 이름 | 효과 | 플레이 |
|---|---|---|
| 폭발형 (기존 A) | 발동 시 폭발 피해, 필드 지속 절반 `폭발` | 즉발 화력 |
| 장기형 (기존 B) | 필드 지속 2.5배·반경 +20%, 감속 중첩 | 영역 장악 |
| **지뢰밭** | 덫 최대 5개·충전 5, 충전 쿨다운 절반, 필드 반경 50% | 맵 전체를 촘촘히 |
| **과충전 덫** | 덫 1개만, 반경 2배, 발동 시 1.5초 구금 `구금` | 거대한 함정 하나에 몰아넣기 |
| **사냥개 덫** | 설치 후 감지 반경 220 안의 적에게 기어가서 발동 | 깔고 잊어버리는 덫 |

**숙련**

| 이름 | 효과 |
|---|---|
| 자동 재설치 (자동화) | 충전이 차면 마지막 발동 지점에 자동 설치 |
| 연쇄 발동 | 덫이 발동하면 400 안의 다른 덫도 같이 발동 |
| 처형장 | 필드 안에서 적이 죽으면 그 필드 지속 +0.5초 (최대 2배) |
| 덫 고리 | 필드에 들어온 적에게 표식 3초 `표식` |

### 5.4 랑데뷰 (E)

**형태**

| 이름 | 효과 | 플레이 |
|---|---|---|
| 충격파 (기존 A) | 출발·도착 지점 충격파 `폭발` | |
| 안전 귀환 (기존 B) | 귀환 후 1초 무적, 헤드헌터 탄창 가득 | |
| **덫 귀환** | 앵커가 없다. 대신 **조준점에 가장 가까운 내 덫으로 순간이동**하고, 그 덫은 즉시 발동 | 덫이 곧 이동 경로. 지뢰밭과 조합하면 맵 전체가 텔레포트 망 |
| **잔상** | 출발 지점에 분신을 남김. 적은 2초간 분신을 노리고, 분신은 사라질 때 폭발 `폭발` | 어그로 빼기 |
| **이중 앵커** | 앵커 2개. 귀환 시 조준점에 가까운 쪽으로 | 두 거점 운용 |

**숙련**

| 이름 | 효과 |
|---|---|
| 비상 귀환 (자동화) | HP 30% 이하가 되면 쿨다운이 돌아 있을 때 자동 귀환 |
| 귀환 장전 | 귀환 직후 주무기 즉시 재장전 + 다음 탄창 관통 +2 `재장전` |
| 공간 왜곡 | 출발~도착 경로 위의 적에게 피해 + 취약 |
| 전술 리셋 | 귀환하면 트레이드마크 충전 +1 |

### 5.5 헤드헌터 (Q, 유지)

**형태**

| 이름 | 효과 | 플레이 |
|---|---|---|
| 연쇄 헤드샷 (기존 A) | 명중마다 피해 +6% (5중첩) | |
| 관통 탄창 (기존 B) | 관통 +3, 탄창 14 | |
| **한 발의 미학** | 탄창 1발, 피해 ×6, 처치하면 탄 회수 | 한 발씩 정확히. 원샷 저격수의 핵심 |
| **속사** | 정조준 감속 없음, 연사 ×2, 크리 확정 해제 | 뛰면서 난사 |
| **표식 사격** | 명중한 적에게 표식 4초. 표식 적에게 주무기 탄이 약하게 유도 `표식` | 지휘관형 |

**숙련**

| 이름 | 효과 |
|---|---|
| 정지 사수 (자동화) | 0.6초 이상 멈춰 있으면 Q 없이도 자동 정조준 (해제 시 즉시 원래대로) |
| 헤드샷 회수 | 조준점 헤드샷(8.3)으로 처치하면 탄 2발 회수 |
| 처형 | HP 20% 이하 적은 권총에 맞으면 즉사 (엘리트·보스 제외) |
| 반사 신경 | Q 유지 중 첫 피격 무효 (8초 쿨다운) |

### 5.6 투르 드 포스 (X)

**형태**

| 이름 | 효과 |
|---|---|
| 2발 장전 (기존 A) | 오브 1회 충전으로 2발 |
| 대폭발 (기존 B) | 피해 +40%, 처치 폭발 반경 3배 |

## 7. 레벨업 카드

### 7.1 카드 종류와 비율

| 종류 | 내용 | 가중치 |
|---|---|---|
| 스킬 | 스킬 해금·레벨 (Lv2·Lv5 도달 시 증강 선택) | 1.5 |
| 전술 | 7.2의 조건부 효과 카드 | 1.2 |
| 생존 패시브 | 7.3 | 0.4 (1장당) |
| 총기 개조 | 기존 4종 + 탄창 | 0.8 |

- **희귀도**: 일반 60 / 희귀 30 / 전설 10. 전설은 레벨 10 이상부터 등장 (합성 포함).
- **시너지 가중**: 보유한 요소와 공유하는 태그가 있으면 가중치 × (1 + 0.3 × 공유 태그 수), 최대 ×2. 빌드가 자연스럽게 수렴한다.
- **리롤 2회 / 추방 2회** (판당). 추방한 카드는 그 판에서 다시 나오지 않는다. 상점에서 리롤 추가 구매 가능.
- 카드에는 태그 칩과 "시너지 +n" 배지를 표시한다.

## 8. 총기 시스템

### 8.1 탄창과 재장전 → 보조무기 전환

- 모든 총에 `magazine`(탄창)과 `reloadTime`(재장전 시간)을 둔다.
- **주무기에 탄이 있으면 주무기만 발사한다. 주무기 재장전 중에는 보조무기가 자동으로 대신 쏜다.** 주무기가 없으면(에코) 보조무기가 상시 발사.
- 보조무기는 "재장전 틈을 메우는 무기"라는 발로란트다운 역할이 생기고, `재장전` 태그 축(탄피 회수, 마지막 한 발, 귀환 장전)이 열린다.
- 헤드헌터 정조준 중에는 지금처럼 주무기 대신 권총.

| 총 | 탄창 | 재장전 |
|---|---|---|
| 밴달 | 25 | 2.5초 |
| 스펙터 (신규) | 30 | 2.25초 |
| 저지 | 7 | 2.2초 |
| 오퍼레이터 | 5 | 3.7초 |
| 클래식 / 셰리프 | 무한 (보조) | - |

### 8.2 이동 중 정확도

- 총마다 `spreadStill`(정지)과 `spreadMove`(이동) 탄 퍼짐을 둔다.
- 오퍼레이터·셰리프·밴달은 이동 중 크게 퍼진다. 스펙터·저지·클래식은 이동 사격에 강하다.
- 카이팅 vs 멈춰 쏘기의 리듬이 총마다 달라지고, 정지 사격·런앤건·정지 사수 같은 카드가 의미를 갖는다.

### 8.3 조준점 헤드샷

- 탄이 적에게 명중할 때 **마우스 조준점이 그 적의 원(반경 + 8) 안에 있으면 헤드샷 = 크리**.
- 자동 사격 게임이어도 실제 조준 실력이 보상받는다. 헤드샷은 이벤트로 남겨 숙련 증강(헤드샷 회수)에서 쓴다.
- **자동 조준(모바일)일 때는 조준점 판정 대신 명중마다 헤드샷 확률 25%** (v0.2.1). 자동 조준은 항상 적 중심을 노리므로 판정을 그대로 쓰면 전부 헤드샷이 된다. input에 `autoAim: true`를 실어 코어가 구분하고, 확률은 시드 RNG로 뽑는다. 데스크톱에서 스킬 자동만 켠 경우 조준은 마우스이므로 조준점 판정을 쓴다.
- 헤드샷 관련 카드·증강(헤드샷 회수, 탄피 회수 등)은 두 방식 모두에서 똑같이 작동한다.
- 기존 `critChance`는 유지하되 낮춘다(셰리프 15% → 8%, 오퍼레이터 25% → 12%).

### 8.4 신규 총: 스펙터 (주무기, 1600)

- 이동 사격 특화 SMG. 피해 14, 연사 9/s, 이동 정확도 페널티 거의 없음.
- 귀환 교란자·런앤건 빌드의 기반.

### 8.5 태그 공명 진화 (다대다)

v0.1의 "총 티어 3 + 지정 스킬 Lv3"를 대체한다.

- **태그 공명**: 보유한 형태·숙련 증강, 전술 카드, 유틸, 유물에 붙은 태그 수를 센다. 어떤 태그가 4개 이상이면 그 태그가 "공명"한다.
- **진화 조건 = 총 티어 3 + 그 총의 진화 경로 중 하나의 태그가 공명.**
- 두 경로 이상이 동시에 열리면 `pending`으로 선택지를 띄운다.
- 요원과 무관하게 동작하므로, 새 요원이 추가돼도 진화 경로가 자동으로 열린다.

| 총 | 경로 1 | 경로 2 | 경로 3 |
|---|---|---|---|
| 클래식 | `장판` 삼연격: 조준점이 장판 안이면 3점사 (기존) | `폭발` 작렬탄: 명중 시 반경 40 소폭발 | `표식` 추적탄: 표식 적에게 유도 |
| 셰리프 | `크리` 집행자: 6연속 크리 시 즉시 재장전 (기존) | `제압` 침묵탄: 명중 시 제압 2초 | `경제` 황금 셰리프: 처치 시 크레딧 +5, 보유 1000당 피해 +5% |
| 밴달 | `이동기` 급습: 이동기 후 3초 연사 +50% (기존) | `저격` 원탭: 탄창 첫 발 크리 확정·관통 2 | `취약` 부식탄: 명중 시 취약 1초 |
| 스펙터 | `이동기` 질주: 이동 중 연사 +30% | `설치물` 공학 탄창: 재장전할 때마다 발밑에 소형 설치물(요원의 C) 1개 | `재장전` 확장 탄창: 탄창 ×2 |
| 저지 | `감속` 처형: 처치 시 다음 사격 펠릿 +3 (기존) | `장판` 화염 펠릿: 착탄 지점에 1초 장판 | `이동기` 반동 도약: 발사 시 뒤로 짧게 도약 |
| 오퍼레이터 | `저격` 관통 증폭: 관통마다 다음 대상 피해 +25% (기존) | `설치물` 덫 각인탄: 마지막 관통 지점에 요원의 C 설치물 생성 | `표식` 표식탄: 명중 적 표식, 표식 적 관통 시 피해 ×2 |

### 8.6 엘리트 무기 드롭

엘리트는 처치 시 무기 상자를 떨어뜨린다. 그 라운드 기준 티어의 무작위 주무기. 밟으면 교체 제안(`pending`), 무시해도 된다.

## 9. 유틸 슬롯: 용병 계약

발로란트에서는 스킬을 크레딧으로 산다. 이를 가져와 **고정 킷 밖의 다섯 번째 슬롯**을 만든다.

- 키: **마우스 우클릭** (확정, v0.2.1). 발사가 자동이라 우클릭이 비어 있다. F도 같은 동작으로 둔다. 모바일은 스킬 칸 위의 다섯 번째 칸 (22장).
- 스킬 자동 사용 중에는 유틸도 자동으로 쓴다. 유틸마다 자동 규칙을 가진다 (21.3).
- 상점 무작위 칸에 다른 요원의 **경량판 스킬**이 매 라운드 2개 등장한다.
- 계약 구매(영구) → 매 라운드 충전 1개 무료, 충전 추가 구매 200 (최대 3). Lv2·Lv3 업그레이드도 상점에서.
- 슬롯은 1개. 교체하면 기존 계약은 사라진다 (유물 "쌍둥이 슬롯"으로 +1).
- 각 유틸은 태그를 가져서 태그 공명에 기여한다.
- 신규 요원 후보를 정식으로 만들기 전에 **유틸로 먼저 실험하는 파이프라인** 역할도 한다.

| 유틸 | 원작 | 태그 | 가격 | 효과 | Lv3 |
|---|---|---|---|---|---|
| 정찰 화살 | 소바 | 표식 | 800 | 착탄 지점에서 반경 300 스캔 2회, 감지 적 표식 4초, 은신 해제 | 스캔 3회 + 벽 반사 1회 |
| 추적자 | 페이드 | 표식 | 700 | 가장 가까운 엘리트·은신 적을 쫓아가 3초 근시 (사격·돌진 불가) | 2기 발사 |
| 제로/포인트 | 케이오 | 제압 | 900 | 칼 착탄 반경 220 적 제압 5초 + 표식 | 반경 +50% |

### 12.2 맵 데이터와 벽

- 맵은 `src/data/maps.js`로 옮긴다. core가 충돌을 판정하고 시뮬레이터 봇도 같은 맵을 써야 하므로, **렌더(`tiles.js`)는 이 데이터를 그리기만 한다.**
- 월드 2000×2000 유지. 충돌·경로 격자는 40 단위(50×50), 아래 스케치는 100 단위(20×20)로 배치 의도만 보인다.
- 벽은 플레이어·적·탄(아군·적군 모두)을 막는다. 적 원거리 탄이 막히므로 엄폐가 생긴다.
- **적 이동 = flow field**: 50×50 격자에서 플레이어 칸 기준 BFS를 플레이어가 칸을 옮기거나 문·텔레포터 상태가 바뀔 때만 다시 계산. 모든 적이 공유하므로 500마리도 비용이 낮고 결정적이다. 텔레포터 두 끝은 BFS 간선(비용 3칸)으로 넣는다.
- **스폰 = 게이트 70% + 시야 밖 무작위 30%.** 적이 정해진 입구에서 들어오므로 길목에 덫을 까는 플레이가 성립한다. 게이트 반경 200 안에는 플레이어 설치물을 놓을 수 없다 (스폰 캠핑 방지).
- `tests/maps.test.js`로 검증한다: 문을 열든 닫든 모든 통행 칸이 시작 위치에서 이어져 있을 것(텔레포터 포함), 문을 닫아도 각 사이트에 다른 입구가 남을 것, 게이트·스파이크·시작 위치가 벽 위에 있지 않을 것. 아래 스케치는 이 조건으로 검증한 것이다.

```js
// src/data/maps.js (형태 예시)
ascent: {
  name: '어센트',
  walls: [[x, y, w, h], ...],               // 월드 좌표 사각형
  gates: [[x, y], ...],
  sites: { A: [x, y, w, h], B: [...] },
  spikes: [[x, y], ...],                    // 해체 라운드 지점
  start: [x, y],
  devices: [
    { type: 'door', rect: [...], switch: [x, y], holdTime: 1, startOpen: true },
    { type: 'teleporter', a: [x, y], b: [x, y], radius: 30, enemyCooldown: 3, throughput: 6, exitInvuln: 0.5 },
  ],
},
```

### 12.3 맵 3종

범례: `#` 벽 · `.` 바닥 · `A` `B` `C` 사이트 · `S` 스파이크 지점 · `G` 게이트 · `P` 시작 위치 · `D` 철문 · `s` 문 스위치 · `T↔t` `U↔u` 텔레포터 쌍

**어센트 (1막)**: 열린 중앙 광장과 사이트 두 곳. 사이트마다 입구가 셋이고 그중 하나가 철문이다.

```
####################
#AAAAA#...G........#
#AAAAA.............#
#AASAA#..###.......#
#AAAAADs...........#
#AAAAA#........##..#
##..###........##..#
#..................#
#..................#
#........P....##...#
#..##..............#
#..##..............#
#...........####..##
#...........#BBBBBB#
#G.........sDBBBBBB#
#......##...#BBSBBB#
#......##...#BBBBBB#
#............BBBBBB#
#.......G...#BBBBBB#
####################
```

- **철문**: 광장 쪽 스위치 `s` 위에 1초 서 있으면 열림↔닫힘. 닫힌 문은 벽이다 (적·탄 모두 막힘). 라운드 시작은 열림.
- 문을 닫으면 사이트 입구가 3 → 2가 되어 덫 두 개로 막을 수 있다. 입문 맵에서 "길목을 만든다"는 감각을 가르치는 장치.
- 모바일·자동 전투에서도 같은 방식 (버튼 없음). 자동 전투는 문을 건드리지 않는다.
- 해체 라운드 스파이크 지점: A·B 사이트 중앙.

**바인드 (2막)**: 미드가 없다. 가운데 척추 벽 때문에 좌우는 위·아래 긴 통로와 텔레포터로만 이어진다.

```
####################
#AAAAAA#G..........#
#AAAAAA#......#....#
#AAAAAA.......#..u.#
#AAASAA#.##........#
#AAAAAA#.##....##..#
#AAAAAA..##....##.G#
#AAAAAA#.##........#
###..###.##........#
#........##......t.#
#.T......##........#
#....P...##.###..###
#..##....##.#BBBBBB#
#..##....##..BBBBBB#
#........##.#BBBBBB#
#.....#..##.#BBSBBB#
#.....#......BBBBBB#
#G...U#.....#BBBBBB#
#..........G#BBBBBB#
####################
```

- **텔레포터 2쌍** (`T↔t` 중단, `U↔u` 왼쪽 아래 ↔ 오른쪽 위). 들어가면 반대편으로. 플레이어는 출구에서 0.5초 무적.
- 적도 쓴다. flow field가 텔레포터를 지름길로 계산하므로, 플레이어가 건너가면 적 무리가 텔레포터로 몰린다. 적은 개체당 3초 재사용 대기, 텔레포터당 초당 6마리까지만 통과 → **입구에 줄이 생긴다** (나노스웜·과충전 덫 최적 지점).
- 플레이어 설치물은 텔레포터를 통과하지 않는다. 출구 쪽에 덫을 깔아 두고 건너가는 것이 바인드의 기본기.
- 자동 전투(모바일 포함)는 플레이어를 움직이지 않으므로 텔레포터 판단도 없다.

**헤이븐 (3막)**: 위쪽에 사이트 셋, 아래쪽 넓은 공간에 게이트 다섯. 장치 없이 입구 수로 압박한다.

```
####################
#AAAAA#BBBBBB#CCCCC#
#AAAAA#BBBBBB#CCCCC#
#AASAA.BBSBBB.CCSCC#
#AAAAA#BBBBBB#CCCCC#
#AAAAA#BBBBBB#CCCCC#
##..#####..#####..##
#..................#
#..................#
#...##...##...##...#
#G..##........##..G#
#..................#
#.......#..#.......#
#..................#
#..................#
#........P.........#
#..................#
#..................#
#.G......G.......G.#
####################
```

- 게이트가 사방에 있어서 한 길목만 막아서는 버틸 수 없다. 이동기·자동화·광역 빌드가 빛나는 구간.
- 해체 라운드 지점이 3곳 (A·B·C). 보스(R12)는 B 사이트에서 등장한다.

**일정 (기본)**: R1 소탕, R2 소탕, R3 해체, R4 엘리트 / R5 방어, R6 사냥, R7 해체, R8 엘리트 / R9 방어, R10 사냥, R11 엘리트, R12 보스.

**변이 (2막부터, 라운드마다 확률 40%)**: 짙은 안개 (시야 반경 축소 → 정찰 가치 상승), 과충전 (적 이속 +15%, 크레딧 +25%), 라디아나이트 폭풍 (맵에 무작위 피해 장판, 적도 맞음).

## 13. 적: 라디아나이트 변이체 (v0.2.1)

### 13.1 테마

적은 전부 **라디아나이트에 오염된 변이체**다. 몸에 박힌 결정의 색과 모양이 능력을 알려준다 — 결정이 앞에 몰려 있으면 방패, 투명하게 일렁이면 은신, 등에서 빛이 뿜어지면 주변을 지원하는 식이다. 능력은 전부 **제압(3.2)으로 끌 수 있는 것**으로 만든다. 그래야 케이오형 유틸과 제압 빌드가 의미를 갖는다.

이름은 `src/data/enemies.js`에만 둔다. 기존 세 종도 테마에 맞게 이름과 외형만 바꾼다 (수치·AI 그대로).

### 13.2 일반 적

수치는 R1 기준, HP는 기존처럼 라운드 배율 h(R)가 곱해진다. 비용은 스폰 예산.

### 13.5 보스: 거대 변이체 (R12)

기존 보스 구조(이동 + 3단계 + 격노)는 그대로 두고 외형과 단계 장치만 변이체답게 바꾼다. 헤이븐 B 사이트에서 등장.

| 단계 | HP | 기존 패턴 (유지) | 추가 |
|---|---|---|---|
| 1 | 100~66% | 원형 탄막 | 몸의 결정 껍질: 앞쪽 피해 -40% (결정 군주의 축소판) |
| 2 | 66~33% | 원형 탄막 + 돌진 | 단계 진입 시 **결정 기둥 3개**를 A·B·C 사이트에 생성. 기둥이 남아 있는 동안 보스는 받는 피해 -50%. 기둥 HP 300, 깨질 때마다 보스 5초 취약 |
| 3 | 33~0% | 회전 나선 탄막 + 파편충 소환 | 소환이 산란체 1기로 바뀜 (제압으로 멈춤). 단계 진입 시 2초 무적 + 화면 흔들림 |

- 등장 150초 뒤 격노(사격 간격 절반)도 그대로.
- 보스는 감속 절반, 구금 절반 (기존), **제압은 패턴 간격 ×2** (3.2).
- 결정 기둥은 다섯 게이트 사이를 오가게 만들어 헤이븐의 넓이를 보스전에 쓴다.

### 13.6 자동 조준 우선순위

모바일 자동 조준과 시뮬 봇이 같은 순서를 쓴다 (`autopilot.js`).

1. 엘리트·보스가 700 안 (2단계 보스는 결정 기둥이 있으면 기둥 우선)
2. 공명체 → 산란체 (지원형을 먼저 지운다)
3. 120 안의 과충전체 (터지기 전에)
4. 가장 가까운 보이는 적

은신 중인 굴절체는 보이기 전까지 조준하지 않는다.

greedy 봇이 4라운드 엘리트 앞에서 전멸해서 아래처럼 맞췄다. 숫자는 전부 `src/data/enemies.js`·`rounds.js`.

## 15. 자동화와 접근성

**구현됨 (main `1b9f2b2`)**: 일시정지 메뉴의 **스킬 자동 사용** 토글. 모바일은 기본 켜짐, 데스크톱은 기본 꺼짐. 판단은 `src/core/autopilot.js`이고 시뮬레이터 greedy 봇과 같은 코드다.

- 데스크톱 기본은 수동 시전. 숙련 증강의 자동화 4종(요원당)이 수동 플레이어의 "반자동화" 경로다.
- 스킬 자동 사용이 켜져 있으면 모든 스킬·유틸이 21장 규칙대로 쓰이고, 플레이어가 직접 누른 입력도 함께 받는다 (직접 입력이 우선).
- 기록은 따로 나누지 않는다. 기록은 브라우저(localStorage)마다 저장되므로 폰과 PC 기록은 원래 분리되어 있다.

## 16. 시뮬레이터 확장

- **지표 추가**: 아키타입별 승률, 형태·숙련 증강 픽률과 승률, 진화 경로 분포, **빌드 엔트로피**(최종 주 태그 분포의 섀넌 엔트로피), 전술 카드별 승률.
- **목표 추가** (`sim/targets.js`): 어느 아키타입도 승률이 전체 평균의 ±50%를 벗어나지 않을 것, 한 아키타입의 점유율 40% 이하.
- **synergy 봇**: 보유 태그와 겹치는 카드를 우선하는 봇. 증강은 아키타입 목표표를 따르는 정책 (`--archetype trapper` 등으로 고정 가능).
- 모든 신규 기능은 봇 대응을 같이 넣는다 (벽 → flow field 이동, 정확도 → 정지 판단, 헤드샷 → 자동 조준 확률).
- **시뮬 승률 = 모바일 자동 모드의 기준선.** 봇의 스킬·조준 판단이 모바일 자동 전투와 같은 코드이므로, 증강을 넣을 때 자동 규칙(21장)을 같이 넣지 않으면 시뮬도 그 증강을 제대로 쓰지 못한다. 형태·숙련 증강의 승률 표는 곧 "자동 규칙의 질" 지표이기도 하다.

## 21. 자동 전투 규칙

모바일과 "스킬 자동 사용"에서 스킬·유틸을 언제, 어디에 쓰는지 정하는 규칙. 지금의 `autopilot.js`는 스킬마다 하드코딩된 if문이라, 형태가 바뀌는 증강이 들어오면 쓸 줄을 모른다. 그래서 **규칙을 데이터로 만들고, 증강마다 자기 규칙을 가지게 한다.**

### 21.1 설계 원칙

1. **규칙 없는 증강은 없다.** 형태·숙련 증강, 유틸, 합성은 모두 `auto` 필드를 가진다. 규칙이 비어 있으면 테스트가 실패한다.
2. **"괜찮게" 쓰면 된다, 최적일 필요는 없다.** 수동 플레이의 상한은 자동보다 높아야 한다. 자동은 손이 바쁘지 않은 대신 타이밍이 평범하다.
3. **자동은 플레이어 이동을 방해하지 않는다.** 플레이어를 순간이동시키는 스킬(귀환, 덫 귀환)은 위험할 때만, 이동을 느리게 하는 스킬(정조준)은 엘리트 상대일 때만 자동으로 쓴다 (`gentle`).
4. **직접 입력이 이긴다.** 같은 틱에 플레이어가 직접 누르면 자동 판단은 그 스킬에 대해 쉰다 (1초).
5. **같은 지점에 겹쳐 쓰지 않는다.** 장판·설치물 규칙은 이미 내 장판이 있는 곳(반경 70% 이상 겹침)을 피한다.

### 21.2 규칙 어휘

```js
// src/data/skills.js — 형태·숙련마다
auto: { when: ['crowd', 300, 5], at: 'densest' }
auto: { when: ['hpBelow', 0.35], or: ['surrounded', 120, 6], at: 'safestGadget' } // 덫 귀환
auto: { hold: ['elite', 700], release: ['ammo', 0] }                                 // 정조준
auto: { place: { when: 'ready', at: 'ahead' }, trigger: { when: ['minesHit', 8] } }    // 은닉 지뢰 (2단계)
```

**조건 (`when`)**

| 조건 | 뜻 |
|---|---|
| `ready` | 쓸 수 있으면 바로 |
| `full` | 충전이 가득 찼을 때 (아끼지 않기) |
| `near r` | 가장 가까운 적이 r 안 |
| `crowd r n` | 대상 지점 반경 r 안에 적 n 이상 |
| `surrounded r n` | 플레이어 반경 r 안에 적 n 이상 |
| `elite r` | 엘리트·보스가 r 안 |
| `hpBelow p` | HP가 최대의 p 아래 |
| `line n` | 조준 방향 직선(폭 18) 위에 적 n 이상 |
| `ability r n` | 능력형 적(13장)이 r 안에 n 이상 |
| `hidden r` | 은신 적이 r 안 |
| `minesHit n` | 내 숨긴 장치 범위 안 적 합계가 n 이상 |
| `every t` | t초마다 |

조건은 `or`/`and`로 묶는다. 판단은 6틱(0.1초)마다 한 번, 스킬당 쿨다운이 돌아 있을 때만 계산한다 (성능).

**지점 (`at`)**

| 지점 | 뜻 |
|---|---|
| `self` | 플레이어 위치 |
| `nearest` | 가장 가까운 적 |
| `between` | 플레이어와 가장 가까운 적 사이 2/3 지점 (적이 지나갈 길) |
| `densest` | 반경 r 격자 샘플링으로 적이 가장 많은 지점 (사거리 안) |
| `ahead` | 적 무리 무게중심 방향으로 사거리 70% 지점 (길목 선점) |
| `elite` | 엘리트·보스 |
| `spread` | 이미 깐 설치물에서 가장 먼 사거리 안 지점 (지뢰밭용) |
| `safestGadget` | 주변 적이 가장 적은 내 설치물 |
| `away` | 적 무게중심 반대 방향 (대시용) |

**체임버**

| 스킬 | 형태 / 숙련 | 규칙 |

| 트레이드마크 | 기본·폭발형·장기형 | `near 320` → `between` |

| | 덫 귀환 | `hpBelow 0.35` 또는 `surrounded 120 6` → `safestGadget` |

| 헤드헌터 (유지) | 기본·연쇄·관통 탄창 | 유지: `elite 700` (데스크톱 자동은 `near 500`도), 해제: 탄 0 |

| | 쪼개 쏘기 | `elite 700` 또는 `line 4` |
| | 십자포화 | `surrounded 400 12` |

| 스킬 | 형태 / 숙련 | 규칙 |
|---|---|---|
| 알람봇 | 기본·연쇄·광역·분열봇 | `near 320` → `between` |

### 21.4 자동화 숙련 증강의 자동 모드 효과

스킬 자동 사용 중에는 "대신 써주는" 자동화 증강이 의미가 없으므로, 카드에 두 효과를 함께 적고 모드에 따라 적용한다.

| 증강 | 수동 모드 | 자동 모드 |
|---|---|---|
| 자동 재설치 (C) | 충전이 차면 마지막 발동 지점에 자동 설치 | 덫 충전 +1, 충전 쿨다운 -20% |
| 비상 귀환 (E) | HP 30% 이하 자동 귀환 | 귀환 후 2초 무적, 쿨다운 -25% |
| 정지 사수 (Q) | 0.6초 멈추면 자동 정조준 | 정조준 이속 페널티 없음 → 자동 규칙이 `near 500`으로 넓어짐 |
| 자동 처형 (X) | 오브가 차고 엘리트가 보이면 자동 발사 | 궁극기 필요 오브 -1 |
| 자동 생산 (C) | 충전이 차면 발밑에 자동 배치 | 알람봇 충전 +1, 쿨다운 -20% |
| 자동 투척 (Q) | 밀집 지점에 자동 투척 | 나노스웜 충전 +1, 장판 반경 +20% |
| 자동 재배치 (E) | 멀어지면 쿨다운 무시 재배치 | 포탑 사거리 +30%, 재배치 쿨다운 0 |
| 비상 프로토콜 (X) | HP 25% 이하 무료 미니 락다운 | 같음 (대신 써주는 효과가 아니라 공짜 추가 발동이라 그대로) |

모드는 판 도중 토글할 수 있으므로, 효과는 매 틱 현재 설정을 보고 적용한다 (보유는 하나, 적용만 바뀜).

## 22. 모바일 UI

현재 모바일 화면(버퍼 높이 300)에 v0.2 요소를 넣는 배치.

| 요소 | 위치 |
|---|---|
| 스킬 4칸 | 오른쪽 아래 2×2 (구현됨) |
| 유틸 칸 | 스킬 2×2 왼쪽 위 대각선에 한 칸. 계약이 없으면 숨김 |
| 빌드 버튼 | 왼쪽 위 일시정지 버튼 옆. 누르면 14.2 빌드 화면 (게임 정지) |
| 증강 선택 카드 | 레벨업 카드와 같은 3장. 태그 칩 최대 3개, 자동화 증강은 "수동 / 자동" 두 줄 효과 |
| 은닉 지뢰 동시 발동 | 수동일 때 나노스웜 칸을 길게 누름 (0.4초) |
| 덫 귀환 목적지 | 수동일 때 랑데뷰 칸을 누른 채 드래그하면 그 방향의 덫, 그냥 탭하면 가장 안전한 덫 |
| 정리 페이즈 남은 적 | 화면 가장자리 화살표 (엘리트 화살표와 같은 방식, 색만 다르게) |

- 모바일에서 손가락으로 조준점을 정할 수 없으므로, 조준점이 필요한 스킬을 수동으로 탭하면 **그 스킬의 자동 규칙 `at` 지점**에 쓴다. 즉 자동과 수동의 차이는 "언제"뿐이다.
- 글자는 버퍼 9px 이상만 쓴다 (폰에서 약 11~12 CSS px).
