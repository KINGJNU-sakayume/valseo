# 집중포화 (CROSSFIRE)

체임버 모티브의 뱀서류 트윈스틱 슈터. 설계: [docs/crossfire-design.md](docs/crossfire-design.md)

현재 진행: **M1~M22 + 에이전트 6명(체임버·킬조이·레이나·브림스톤·게코·아스트라)** — 이동·조준·자동 발사, XP 레벨업(스킬·패시브·총기 개조), 12라운드, 크레딧과 구매 페이즈, 스킬 4종(C/E/Q/X)과 감속 필드·집중포화, 적 3종(추격·돌격·원거리) + 엘리트(3·6·9R), 스킬 3레벨 분기 A/B, 총기 진화, 12라운드 보스, 시작/일시정지/결과 화면, 헤드리스 밸런스 시뮬레이터.

> **알림**: 요원·총기·맵 이름은 발로란트에서 따온 임시 이름입니다. 치환은 원할 때 하기로 했습니다(설계 문서 v0.2 20장). 여섯 요원의 밸런스는 0.2.6 에서 한꺼번에 조정했습니다 (설계 문서 v0.2 29장, 아래 "밸런스 시뮬레이션"). 아스트라의 라운드 시작 별 배치(28.4)는 직접 해 본 뒤 정합니다.

## 그래픽·사운드

- 발로란트풍 픽셀 아트. 월드는 저해상도 픽셀 버퍼(화면 높이 약 360px)에 그려 정수 배율로 확대한다.
- 스프라이트(캐릭터·적·총기·아이콘)는 코드의 문자 격자로 생성(`src/render/sprites.js`), 엘리트·보스·바닥 타일은 절차적으로 그린다.
- 효과음은 Web Audio 로 실시간 합성(`src/render/audio.js`). 외부 이미지·사운드 파일 없음.
- 폰트: [Galmuri](https://github.com/quiple/galmuri) (SIL Open Font License 1.1, `assets/fonts/OFL.md`).
- 일시정지(P/Esc)에서 소리·음량·파티클·조명·화면 흔들림·피해 숫자를 켜고 끌 수 있다.
- 에이전트별 최고 기록(최고 라운드, 승리/판 수, 최단 승리, 최다 처치)을 브라우저에 저장한다. 결과 화면에 신기록은 NEW, 에이전트 선택 화면에 기록 요약.

## 실행

ES modules라 `file://`로는 열리지 않으니 로컬 서버가 필요합니다.

```sh
npm run serve        # = python3 -m http.server 8000
# 브라우저에서 http://localhost:8000  (시드 고정: ?seed=42)
```

조작: WASD 이동 · 마우스 조준 (발사는 자동) · 우클릭/F 유틸 · 레벨업/상점은 클릭 또는 숫자 키, Enter = 다음 라운드 · P/Esc 일시정지(이펙트·화면 흔들림·피해 숫자 끄기) · 종료 후 R로 재시작

| 키 | 스킬 | 동작 |
|---|---|---|
| C | 트레이드마크 | 조준점에 함정 설치(충전 2). 적이 밟으면 감속 필드 |
| E | 랑데부 | 앵커 설치 → 다시 E로 앵커 위치 귀환 |
| Q (누르고 있기) | 헤드헌터 | 정조준: 이속 50%, 주무기 대신 크리 확정·관통 권총(탄창 8) |
| X | 역작 | 오브 3개로 관통 저격, 처치 지점에 감속 폭발 |

C는 처음부터 보유, Q/E/X는 레벨업 카드로 해금.

화면 하단 스킬 칸에 키(C/Q/E/X)·스킬 이름·레벨(5칸 막대, 분기 이후 금색)·쿨다운 숫자가 표시되고, 레벨이 오르면 칸이 반짝인다.
일시정지 메뉴의 **스킬 자동 사용**을 켜면 데스크톱에서도 스킬을 자동으로 쓴다.

### 모바일 (웹앱)

휴대폰 브라우저로 Pages 주소를 열면 모바일 모드로 바뀐다 (데스크톱에서 미리 보려면 `?mobile=1`). 가로 화면 전용.

- **이동**: 화면 아무 곳이나 눌러 끄는 가상 조이스틱. **조준·발사·스킬은 자동** (시뮬레이터 봇과 같은 판단, `src/core/autopilot.js`).
- 오른쪽 아래 스킬 칸을 탭하면 직접 사용 (Q 헤드헌터는 누르고 있는 동안 정조준). 일시정지에서 스킬 자동 사용을 끌 수 있다.
- 왼쪽 위 Ⅱ 버튼 = 일시정지. 앱을 내리면 자동 일시정지.
- 홈 화면에 추가하면 전체 화면 앱으로 실행되고, 한 번 연 뒤에는 오프라인에서도 돈다 (`manifest.webmanifest`, `sw.js`).
- 용병 계약이 있으면 스킬 칸 왼쪽 위에 유틸 칸이 생긴다.

스킬이 **Lv2**가 되면 **형태 증강**(동작 방식이 바뀜) 3개 중 하나, **Lv5**에서 **숙련 증강** 3개 중 하나를 고른다. 숙련 중 "자동화"는 스킬 자동 사용 중이면 다른 효과로 바뀐다.

### 에이전트

타이틀 → 에이전트 선택(1~6). 키 슬롯은 같고 스킬 묶음과 고유 패시브가 다르다.

| 키 | 체임버 | 킬조이 | 레이나 | 브림스톤 | 게코 | 아스트라 |
|---|---|---|---|---|---|---|
| C | 트레이드마크: 함정 → 감속 필드 | 알람봇: 다가온 적에게 굴러가 폭발 + 취약 | 눈총: 눈 → 반경 안 적 실명 | 자극제 신호기: 안에서 연사·이속 증가 | 폭파봇 지옥: 던지면 터지는 폭파봇, 끝난 자리에 구슬 | 중력의 샘: 별 → 끌어당긴 뒤 폭발, 취약 |
| Q | 헤드헌터(유지): 정조준 권총 | 나노스웜: 지속 피해 장판 | 포식: 영혼 1 → 회복 | 소이탄: 화염 장판 | 지원봇: 적을 쫓아가 구금 | 신성 파동: 별 → 짧은 충전 뒤 범위 기절 |
| E | 랑데부: 앵커 설치·귀환 | 포탑: 자동 사격 (다시 E: 재배치) | 무시: 영혼 1 → 무적 질주 | 공중 연막: 안의 적 사격 불가, 안의 나는 놓친다 | 기절봇: 날아가 적을 하나씩 눈멀게 | 성운: 별 → 연막 (안의 적 사격 불가) |
| X | 역작: 5발 관통 저격 | 봉쇄: 기동 후 광역 구금 | 여제: 연사 폭주, 처치마다 연장 | 궤도 일격: 2초 예고 뒤 광역 화염 | 요동봇: 날뛰며 닿는 적 구금, 회수하면 오브 1개 환급 | 천상계 형상: 몸을 빠져나와 맵 전체에 별 배치, 궁극기 우주 장벽(두 세계) |
| 패시브 | 집중포화: 감속 필드 안 적은 모든 피해 크리 | 천재성: 취약 적에게 설치물 피해는 크리 | 포식자: 실명 적에게 모든 피해 크리, 처치하면 영혼 구슬 | 거점 사령관: 내 구역 안에서 받는 피해 -10%, 이동 사격 정확도 페널티 없음 | 회수: 구슬을 밟으면 그 스킬 쿨다운이 3초로, 이속 +20% 2초 | 별빛: 별 근처의 적은 받는 피해 +10%, 은신이 풀린다 |

브림스톤은 구역(신호기·연막·화염 장판)을 깔고 그 안에서 버티는 요원이다. 처치로 충전되는 자원이 없고 모두 시간 쿨다운이다. 연막·소이탄은 스킬로 이미 가져서 계약 상점에는 나오지 않는다.

게코는 스킬이 자율 생물이고, 끝난 자리에 남는 구슬을 직접 밟아야 쿨다운이 줄어든다(회수). 처치로 충전되는 자원이 없다.

아스트라는 C/Q/E 가 모두 **별**에서 일어난다. X(천상계 형상)로 몸을 빠져나와 시간이 30%로 느려진 맵 전체 지도에서 별을 놓고 회수하며, 라운드가 시작되면 시간이 멈춘 채 별을 무료로 배치한다. 변환은 조준점에 가장 가까운 별에서 일어나고, 쓴 별은 8초 뒤 같은 자리에 다시 생긴다. 궁극기 우주 장벽은 두 점을 이은 직선으로 맵을 두 세계로 나눈다 (설계 28장).

상태이상: **취약**(받는 피해 ×1.1), **표식**(+10%, 은신 해제), **제압**(능력 정지), **실명**(사격 정지), **구금**(이동·사격 정지, 엘리트·보스는 저항), **냉각**(감속).
에이전트 모듈은 `src/core/systems/agents/*.js`, 데이터는 `src/data/agents.js`·`src/data/skills.js`.

**보스 (12라운드, 거대 변이체)**: 처치하면 승리. 체력 66%/33%에서 단계 전환 — 원형 탄막(앞쪽 껍질) → 돌진 + 결정 기둥 → 회전 나선 탄막 + 산란체 소환. 등장 150초 뒤 격노. 감속·구금은 절반, 제압은 패턴 간격 ×2.

### 총기 (주무기 / 보조무기 슬롯)

주무기를 먼저 쏘고, 탄창을 다 쓰면 재장전하는 동안 보조무기로 바뀐다. 움직이면 탄이 퍼지고, 조준점이 적 위에 있으면 헤드샷(크리, 모바일 자동 조준은 25% 확률).

| 총 | 슬롯 | 성격 | 가격 |
|---|---|---|---|
| 클래식 | 보조 | 시작 무기 | - |
| 셰리프 | 보조 | 단발 고위력 | 1200 |
| 스펙터 | 주무기 | 이동 사격에 강한 기관단총 | 1300 |
| 밴달 | 주무기 | 중속 고연사 | 2100 |
| 저지 | 주무기 | 근접 산탄 | 1500 |
| 오퍼레이터 | 주무기 | 관통 저격 | 2300 |

**진화**: 티어 3(티어 2 → 3 가격 2600) + 태그 **공명**(같은 태그 3개: 전술 카드·증강·패시브·계약·유물) → 그 태그의 진화형. 클래식·셰리프는 경로 3개, 주무기는 7~8개 (폭발·설치물·표식·경제·총기·크리·장판 등, `src/data/guns.js`). 경로가 둘 이상 열리면 고른다.

### 맵과 적 (M15·M16)

1막 **어센트**(R1~4, 사이트 철문: 스위치 위에 1초 서 있으면 여닫힘) → 2막 **바인드**(R5~8, 플레이어·적 공용 텔레포터) → 3막 **헤이븐**(R9~12, 사이트 셋·게이트 다섯). 적은 벽을 돌아 경로를 찾고, 대부분 게이트(붉은 통풍구)에서 나온다. 적 탄은 벽에 막힌다.

적은 라디아나이트 변이체: 파편충 · 돌진수 · 방출체 · **결정갑각**(앞쪽 껍질, 측면·폭발로) · **굴절체**(은신, 표식으로) · **공명체**(보호막) · **산란체** · **과충전체**(자폭, 적에게 더 아프다). 능력은 전부 **제압**으로 꺼진다. 막 엘리트: 결정 군주(R4) · 굴절 포식자(R8) · 산란 모체(R11). 보스(R12)는 2단계에 사이트마다 **결정 기둥**을 세운다 — 기둥이 남아 있으면 피해 -50%.

### 용병 계약과 유물 (M17)

- **상점 무작위 칸**: 계약 2 + 카드 또는 유물 1, 다시 뽑기 200, 레벨업 리롤권 300.
- **용병 계약**(유틸 슬롯, 우클릭/F): 정찰용 화살 · 제로/포인트 · 페인트탄 · 둔화 구슬 · 순풍. 라운드마다 무료 충전 1, 충전 추가 구매, Lv2·Lv3 업그레이드 (`src/data/utils.js`).
- **유물** 12종 (엘리트 처치 시 3지선다, 상점 희귀 칸): 장점과 단점이 함께 있다 — 유리 대포, 권총 고수, 설계자, 도박꾼, 무거운 손, 과열 칩, 엘리트 트로피, 라디아나이트 심장, 탄약 벨트, 쌍둥이 슬롯, 흡혈 코어, 깨진 렌즈 (`src/data/relics.js`).

### 라운드 진행 (M10)

0~70초 스폰 → **정리 페이즈**(스폰 정지, 남은 적 수 표시·머리 위 표식) → 전멸하면 **ROUND WIN**(슬로모, 클리어 보너스 +25%) → 90초까지 남은 적이 있으면 **섬멸 파동**(XP만 주고 처치). 크레딧은 처치 즉시 지급("+15" 팝업, HUD 카운터), 필드에는 XP 보석(값에 따라 소·중·대)만 떨어진다.

### 레벨업 카드 (M11)

스킬 · **전술 카드** · 패시브 · 총기 개조. 스킬 카드는 가중치가 높아(3.5) 자주 나오고, 그래야 스킬이 Lv5 에 닿아 숙련 증강을 고른다. 카드에는 태그와 시너지(보유 태그와 겹치는 수)가 표시되고, 시너지가 높을수록 잘 나온다. 판당 **리롤 2회(R)**, **추방 2회(B, 그 판에서 다시 안 나옴)**. **Tab**(모바일은 왼쪽 위 빌드 버튼)으로 빌드 화면: 보유 카드와 태그 공명 진행도.

- 전술 카드 12종 (`src/data/tactics.js`): 연쇄 반응 · 정지 사격 · 런앤건 · 취약 전염 · 감속 증폭 · 폭발 연쇄 · 쿨다운 순환 · 위기 대응 · 냉혹 · 집중 · 기선 제압 · 정리 전문가
- 패시브 카드 10종: 최대 HP · 이동속도 · 자석 반경 · 방어구 효율 · 처치 회복 · 피격 후 무적 (각 5중첩) + 폭발 · 장판 · 설치물 · 저격 피해 (각 3중첩). XP·크레딧 획득, 크리 피해, 쿨다운, 지속, 오브 드롭은 카드에서 빠지고 유물(M17) 효과로 남는다.
- 태그(`src/data/tags.js`): 모든 피해 출처·스킬·총·카드에 붙어 있어 서로 맞물린다. 상태이상 **표식**(받는 피해 +10%) 추가.

## 테스트

```sh
npm test             # = node --test tests/*.test.js
```

- `tests/core.test.js`: core를 Node에서 실행, RNG/결정성/처치/패배/공간 해시
- `tests/progression.test.js`: 수식, 레벨업 pending, 라운드 전환, 상점, 실드
- `tests/skills.test.js`: 체임버 C/E/Q/X, 감속, 집중포화, 오브, 라운드 정리

## 밸런스 시뮬레이션

```sh
npm run sim          # = node sim/run.js --seeds 300 --bot greedy --out report.json
npm run sim:all      # = 여섯 요원 모두, 100판씩 (요원별 리포트 report-{agent}.json)
node sim/summary.js report.json   # 마크다운 요약 (목표 범위 비교)
```

- `sim/run.js`: 렌더 없이 core 를 최고속으로 돌린다. CPU 코어 수만큼 worker 로 병렬 실행(`--workers`). worker 가 판을 하나씩 가져가는 큐 방식이라 판 길이가 달라도 코어가 놀지 않는다.
- 여러 요원 한 번에: `npm run sim:all` (= `--agent all`, 쉼표 목록도 가능). 요원별 리포트는 `--out` 의 `{agent}` 자리에 저장되고, 끝에 요원별 표를 찍는다. 100판×6요원이 4코어에서 약 10분 걸린다.
- 수치 후보 시험: `src/data/` 를 고치지 않고 패치 파일(JSON)로 돌린다 — `node sim/run.js --agent brimstone --patch sim/patches/example.json`. 형식은 `sim/patch.js` 머리말 (`"SKILLS.ember.dps": { "mul": 0.8 }`, `{ "add": 2 }`, 값 그대로). 객체의 속성만 바뀐다 (`RESONANCE` 같은 숫자 export 는 안 바뀐다).
- 후보 비교: `node sim/compare.js --agent all --seeds 100 --patch a.json --patch b.json` — 원래 수치와 후보들을 같은 시드로 한 풀에서 돌려 승률 차이와 95% 신뢰구간을 표로 낸다. 차이가 ± 보다 작으면 판 수를 늘려 다시 본다. 후보를 고른 뒤에만 `src/data/` 에 옮기고, `npm run sim:all` 로 확인한다.
- `sim/patches/`: 0.2.6 밸런스 후보 (`gun-economy`·`gun-evolutions`·`skill-supply`·`enemy-scaling`·요원별 `*-nerf`/`*-buff`·`augment-tags`). 모두 **0.2.5 수치 기준**이라 이미 옮긴 `src/data/` 위에 다시 얹으면 두 번 적용된다 (`balance-0.2.6.json` 이 전부 묶은 것, 기록용).
- `sim/bots/greedy.js`: 가장 가까운 적 조준, 적 밀집 반대 + 조각 쪽 이동, 기본 스킬 사용, 카드는 스킬 > 전술 > 개조 > 패시브, 상점은 고정 우선순위. **주무기 선호와 맨 앞 스킬은 시드마다 돌려서**(`--gun`·`opts.skill` 로 고정 가능) 총·증강 데이터가 고르게 쌓이게 한다.
- `sim/targets.js`: 목표 범위 (승률 10~30%, 평균 생존 8~11라운드, 12라운드 도달 시 레벨 18~22, 진화 발생률 40~75%).

현재 밸런스 (요원별 100판, 시드 1~100, 보스 포함, 0.2.6):

| 에이전트 | 승률 | 평균 생존 | 12R 레벨 | 진화 |
|---|---|---|---|---|
| 체임버 | 14% | 8.5 | 20.2 | 47% |
| 킬조이 | 21% | 8.7 | 20.3 | 50% |
| 레이나 | 20% | 8.2 | 21.1 | 46% |
| 브림스톤 | 28% | 8.8 | 20.3 | 53% |
| 게코 | 29% | 9.1 | 20.2 | 48% |
| 아스트라 | 20% | 8.8 | 20.1 | 42% |

100판의 승률 오차는 ±9%p 안팎이다 (그래서 결정은 원인 분리 → 50판 후보 비교 → 100판 확인 순서). 과정과 남은 문제는 설계 문서 29장.

greedy 봇은 주무기 선호(밴달·저지·오퍼레이터·스펙터)를 시드마다 돌려 총기별 승률도 리포트한다.
분기별 강약은 `--branch A|B|alt` 로 봇의 분기 선택을 고정해 비교한다 (리포트의 분기별 승률 표).

## 패치노트

밸런스·기능 변경을 게임사 패치노트처럼 카드뉴스 PDF(1080×1350, 카드 한 장 = 한 쪽)로 남긴다.

```sh
npm run patchnotes -- patchnotes/0.2.6.json         # → patchnotes/0.2.6.pdf (+ 확인용 .html)
npm run patchnotes -- patchnotes/0.2.6.json --png   # 카드별 PNG 도 (patchnotes/0.2.6/)
```

- 내용은 JSON 하나(`patchnotes/<버전>.json`): 카드 종류는 `cover`·`summary`·`agent-new`·`changes`·`guns`·`extra`·`chart`·`outro`. 0.2.5·0.2.6 이 예시.
- 변경 줄은 `{ "label": "초당 피해", "before": "40~64", "after": "18~29" }`, 태그는 `buff`(상향)·`nerf`(하향)·`change`(변경)·`new`(신규). `changes` 카드는 `agent` 없이도 쓸 수 있고(`"kicker"` 로 윗줄 글자 변경), 항목이 4개 이상이면 촘촘하게 그린다.
- 그림은 게임 스프라이트(`src/render/art`)를 그대로 쓰고(`"showcase": ["turret", …]`), 폰트도 게임의 Galmuri. 요원 카드 아래 `showcase` 에는 그 요원 스프라이트를 넣는다.
- PDF 에는 Playwright 가 필요하다: `npm i -D playwright && npx playwright install chromium`. 없으면 HTML 만 만든다.
- `--png` 로 카드를 눈으로 확인한다: 글이 넘치거나(카드 위·아래 띠가 눌려 보인다) 빈 곳이 큰 카드는 문장을 줄이거나 항목을 더한다.
- 밸런스 패치를 마치면 `sim:all` 결과로 `chart` 카드 수치를 채우고, `before` 칸에 이전 승률을 넣는다.
